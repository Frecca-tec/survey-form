# Survey Form（メンター予約フォーム）

## 概要
PHP + MySQLで作成したメンター予約フォームです。  
入力内容のバリデーション、データ保存機能を実装しています。
今後も機能拡張を予定しています。
Qiitaで作成過程を公開しています。

※現在開発中のプロジェクトです。

## 機能
- 入力フォーム（名前・メールアドレス・予約日時・相談内容など）
- バリデーションチェック（未入力・形式チェック）
- データベース保存
- 確認画面・完了画面

## 工夫した点
- フォームのレイアウトを整理し、入力項目を視覚的に分かりやすく配置
- 入力ミスを防ぐため、必須項目チェックや形式チェックを実装
- エラーメッセージを具体的に表示し、ユーザーが修正しやすいように設計
- チェックボックスの複数選択データを配列で受け取り、表示用に整形処理を実装
- スライダー下の目盛りラベルは、位置がずれないようにスライダーと同じ幅に揃えた。
  また、各目盛りの表示幅を固定し、数字と補足ラベルが縦に揃って見えるよう調整した。
- スライダー操作時に、緊急度（対応の優先度）の数値がリアルタイムで更新されるように実装しました。
  ユーザーが現在の選択値を直感的に把握できるようにすることで、入力ミスの防止とUX向上を意識しています。
- 必須項目未記入時のエラー表示
